# MicroBench 显微颗粒观察工作台

本地显微图像颗粒量测与复核工具。访问 http://127.0.0.1:18920 ，点击“载入合成演示”，选择视野并“应用设置并分析”，在叠加图和量测表核对对象。演示由程序绘制，并非真实显微照片；结果是图像量测近似，不用于医疗诊断。双通道共定位与随机错位对照请从“载入双通道演示”开始。

双通道对照：在同一工程选两幅已对齐、同尺寸视野，用共同多边形ROI、各自阳性阈值查看A绿B品红叠加、联合强度散点和相关性，以及各通道阳性强度中落在另一通道阳性区域的份额。随机错位对照把B通道整体平移整数像素，只取使共同ROI完整留在图像内且不落入透明区的位移，在环带范围内均匀抽取，保留斑点尺寸与形态；不逐像素打散、不环绕越界信号、不用外接矩形。ROI过小、阳性像素不足、可用位移太少或超出计算预算时明确显示“对照不可用”及原因。保存结果固定当时两幅源图、共同ROI、阈值、对照设置、实际平移记录与分布，之后修改视野或阈值不改变旧结果；可单独导出ZIP。原来的单视野量测与历史不受影响。

正常功能包括多视野PNG/JPEG/单页TIFF/WebP导入及EXIF方向处理、单/多条标尺最小二乘物理标定、源图多边形ROI、三种阈值及形态学对象提取、标签图与对象叠加、物理面积/周长/等效直径/椭圆轴量测、对象强度积分与圆度、人工排除对象并保留历史结果、带标定距离的强度线剖面、源图距离/角度/面积标注、图像曝光与清晰度读数、批次视野数密度/粒径比较、命名快照恢复、不可变分析历史、PNG/标签图/CSV/清单结果交付、完整可编辑工程ZIP往返。观测时刻是元数据，目前各视野独立量测，没有跨帧对象身份、运动轨迹或分裂合并谱系。

图像像素中心坐标为整数x/y，原点左上，x右y下。物理标定为各向同性，每像素长度。标尺参考用已知长度对像素距离的零截距最小二乘拟合。显示图缩放不改变源坐标。强度是RGBA先以黑底合成后按固定RGB亮度权重计算的0–1显示色值；不是光子计数或已做仪器辐射标定的数据。透明像素不进入ROI，边界对象可排除。面积为标签像素数，周长为像素中心轮廓长度，椭圆轴来自像素点协方差。填孔不跨ROI无效区。对象ID仅在对应分析结果内有意义，每次分析重新编号；历史量测固定保存当时源图、标定、ROI与设置。修改这些输入会失效当前结果，旧结果仍可查看下载。排除选择创建新结果，旧结果不变。新分析发布时核验工程revision，期间修改则拒绝旧发布。

启动 `docker compose -p solo20-microbench up -d --build`，持久数据为独立命名卷 `solo20-microbench-data`；删除容器保留卷，`down -v`删除数据。也可按requirements安装依赖后执行 `./start.sh`；Python3.11/3.12按条件锁定依赖。`MICROBENCH_DATA_DIR`与`PORT`指定数据和端口。

预算：单图20MB、1200万像素、边长4096，每工程32图、100份分析、100份双通道对照、30快照，每幅分析2000对象，ROI/标注最多100顶点；对照每次至少19次、至多999次，ROI像素×次数不超过1.5亿像素次。工程ZIP96MB压缩、192MB展开、500成员。所有计算CPU同步；实际验证512×360合成视野，不承诺极限规模实时性能。阈值法适用于背景与对象可分辨的二维图像，不含深度学习识别、语义分类、粘连自动分裂、三维体积重建、仪器畸变补偿或真实光谱解混。

`/bench/pair/demo`载入双通道合成演示（共享斑点加各自独立斑点，附带窄不规则ROI）。接口：`POST /bench/projects/<pid>/pairs/preview`只返回当前设置的结果，`POST /bench/projects/<pid>/pairs`保存，`GET /bench/projects/<pid>/pairs/<pair_id>`与`.../image/overlay.png`、`.../image/participation.png`读取，`.../export.zip`导出。工程ZIP往返包含对照源图与渲染，导入时校验尺寸。

`/prepare`为完整自有图像准备工具，其`image_lab`及`prepare.html`、`app.js`、`style.css`按字节复用自本工作区solo_19正常版本，供量测前配准、色彩/曝光、图像合成和区域处理。准备结果下载后导入MicroBench；未混入旧项目动态影像编排业务。MicroBench新业务在`microbench/`和`bench.*`中，负责视野、标定、对象、量测、历史、工程及交付。后台统计仅包含实际Python后台，排除前端、文档、脚本、依赖和生成数据。
